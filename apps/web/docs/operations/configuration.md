# Configuration reference

All keys are **testnet-only** and live in the gitignored root `.env` (template: `.env.example`). Nothing secret is ever committed.

## Root `.env`

| Variable | Used by | Meaning |
| --- | --- | --- |
| `RPC_URL`, `RPC_WS_URL` | everything | Monad Testnet RPC |
| `DEPLOYER_KEY` | scripts | deploys and seeds; admin on testnet |
| `RELAYER_KEY` | relay, CRE CLI | `RELAYER_ROLE`; also `CRE_ETH_PRIVATE_KEY` in `cre/.env` |
| `PROVIDER_A_KEY`, `PROVIDER_B_KEY` | agent, mm | provider wallets |
| `NODE_A_KEY`, `NODE_B_KEY` | agent | node keys that sign hour summaries |
| `PROBE_KEY` | probe | signs the probe's hour summaries |
| `MM_KEY` | mm | market-maker wallet |
| `BUYER_A_KEY`, `BUYER_B_KEY` | demo scripts | labelled test buyers |
| `JUDGE_KEY` | seed | the funded judge wallet (shared privately, never in the repo) |
| `ENVIO_API_TOKEN` | local indexer | HyperSync token (optional; `RPC_ONLY=1` works without it) |
| `DEMO_HOUR_SECONDS` | deploy | delivery-hour length for the demo series (default 300) |
| `MON_PER_WALLET` | seed | gas sent to each service wallet (default 0.25 MON) |

## Web app (`apps/web/.env.example`)

| Variable | Meaning |
| --- | --- |
| `NEXT_PUBLIC_RPC_URL`, `NEXT_PUBLIC_RPC_FALLBACK` | RPCs |
| `NEXT_PUBLIC_ENVIO_URL` | Envio GraphQL endpoint |
| `NEXT_PUBLIC_AGENT_URL`, `NEXT_PUBLIC_PROBE_URL` | demo controls on `/tickets` |
| `NEXT_PUBLIC_PROVIDER_A`, `NEXT_PUBLIC_PROVIDER_B`, `NEXT_PUBLIC_PROBE_ADDRESS` | names and keys shown in the UI (public) |
| `NEXT_PUBLIC_HOUR_SECONDS` | delivery-hour length shown in the UI |
| `NEXT_PUBLIC_WALLETCONNECT_ID` | optional WalletConnect project id |
| `NEXT_PUBLIC_SITE_URL` | for link previews |
| `NEXT_PUBLIC_DEV_BURNER_KEY` | **localhost only**, a test key for scripted testing. Never set in production |
